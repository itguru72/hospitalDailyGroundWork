1. Getting started

↑ Top
  1. Open ⚙ Settings → set Active Unit.
  2. Choose a Theme (Fresh Green / Light / Dark…).
  3. On each ward, use ⚙ to set bed count and ward code (e.g. RCVRY1).
Data saves automatically in this browser (localStorage). Export for backup.

4. Beds & drag

↑ Top
  • Ward code → beds named CODE-B01; loan-in CODE-LB01
  • Drag bed → unit chip = Loan out
  • Drag unit chip → ward = Loan in
  • Drag patient bed → empty bed = Move
  • Double-tap unit chip = choose Loan In or Out
Active unit is hidden from the chip strip. Only other units show.
↑ Back to top

5. Loans

↑ Top
  • ↓ Lend In (green) — receive bed from another unit
  • ↑ Lend Out (amber) — give owned bed away
  • Doctor list is for the receiving unit
  • Cannot loan to/from the same active unit
↑ Back to top

6. Patients

↑ Top
  • BPL — normal beds only · APL — can use side rooms
  • General summary — latest hand-over snapshot
  • Work notes — date/time log; type note and Save
  • Discharge — restore later from Patients list
  • Bed moves stay in bed allocation history
↑ Back to top

7. OT / Reserve

↑ Top
  1. Select patient
  2. Reserve empty / next-in-line / move now
  3. Pick ward, then bed (includes lent-in)

Occupied target: discharge · return to original · swap (BPL only).

↑ Back to top

8. Hand Over Report

↑ Top

☰ → Hand Over Report

  • Wards, loans, patient list, patient detail
  • ⬇ Download — list + detailed reports (summary, work notes, bed history)
  • Export colours follow current theme
↑ Back to top
